# 大宗物流运输方案智能体助手 - 订阅式服务 Demo
> 定位：面向钢厂、大宗贸易公司、第三方物流企业的订阅式智能体服务，输入企业自有基础数据，自动生成A到B多式联运运输方案，支持【最省成本】/【最快时效】两种优化目标。

## 一、项目简介
本智能体助手是标准化可订阅的SaaS化智能服务，核心能力：输入起运地A、目的地B、货物信息、企业自有运力/运价/场站约束，智能体自动完成多式联运路线寻优，输出量化运输方案。
客户不需要从零搭建整套AI系统，按版本订阅服务，接入自己企业数据即可使用。
- 服务对象：钢厂、大宗贸易商、第三方物流公司
- 货物类型：铁矿石、焦炭、煤、钢材、矿粉等大宗散货/件货
- 优化目标二选一：优先成本（最省）｜优先时效（最快）
- 运输方式：公路、铁路、内河/海运多式联运组合
- 订阅模式：按企业账号订阅，支持基础版、专业版、企业集群版阶梯订阅

## 二、核心功能范围
1. **数据源管理**
    - 企业私有数据源：自有运价、合作场站、运力约束、运输业务规则维护
    - 外部生态数据源：气象天气、区域参考运价、路网限行限重、港口船期、场站装卸动态等公共生态数据接入
2. **运输询价**
    - 对接包含中外运、海程邦达在内的百余家主流货运供应商资源池
    - 根据运输需求发起实时询价，获取各家供应商最新报价，自动筛选低价方案
    - 询价结果可和智能路线方案联动比对，辅助业务决策
3. 运单需求输入
    - 起运地A、目的地B、货物品类、重量、体积、装货时间要求
    - 选择优化目标：【最省成本】 / 【最快时效】
4. 智能体自动推理计算
    - 融合公共路网、限重限行、港口船期、铁路班列时刻 + 企业私有数据
    - 枚举多条可行联运方案，量化对比：总成本、总时长、中转节点、滞港/压车风险、装卸等待时间
    - 输出推荐主方案 + 备选方案，附带决策理由
5. 扰动重规划（专业版及以上）
    - 模拟/接收外部扰动：封路、船期延误、堆场爆满、运力临时取消
    - 智能体自动重算，生成替代运输方案，输出变更影响评估
6. 方案导出与业务联动
    - 方案报表导出、路线可视化、支持和客户现有业务流程打通流转
7. 扩展能力（企业集群版订阅解锁）
    - 和调度智能体、货权风控智能体、料场智能体联动，接入物流控制塔协同

## 三、订阅套餐说明（Demo演示用）
> 所有套餐底层是同一个智能体服务，差异在于数据权限、扰动重规划、运输询价、业务联动、集群协同能力
1. 基础订阅版
    - 能力：A-B路线方案推荐，仅基础公共路网运价，手动录入运单，导出PDF方案
    - 适合：中小贸易商、小型物流公司
2. 专业订阅版
    - 能力：支持上传企业自有运价、自有运力库、企业约束；支持扰动重规划；地图可视化；**运输询价功能**
    - 适合：中型物流公司、独立贸易企业
3. 企业集群订阅版
    - 能力：全部专业版能力 + **业务流程互通** + 对接其他大宗智能体集群、控制塔联动、多账号子权限
    - 适合：钢厂、大型供应链集团

## 五、用户操作流程（Demo交互流程）
1. 企业完成订阅，登录后台，录入/导入企业专属基础数据（运价、场站、自有运力、约束规则），平台自动拉取外部生态数据
2. 录入运输需求信息，可先发起【运输询价】，批量获取多家货运商实时报价，比价参考
3. 提交运单需求，选择优化目标：优先成本 / 优先时效，点击【生成运输方案】
4. 智能体开始推理（页面展示思考日志）
5. 返回结果：推荐方案 + 备选方案，地图展示联运路线，表格对比成本、时效、风险，可和询价结果对照
6. 专业版可触发【模拟扰动】，智能体自动重规划出新方案
7. 查看、导出方案、询价记录，推送至内部业务链路
