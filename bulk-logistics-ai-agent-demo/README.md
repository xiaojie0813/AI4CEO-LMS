# 🛰️ 铁流智运 BulkFlow AI · 大宗物流运输方案智能体助手（订阅式服务 Demo）

> 面向钢厂、大宗贸易公司、第三方物流企业的订阅式智能体服务演示
> 输入企业自有基础数据，自动生成 A→B 多式联运运输方案，支持【最省成本】/【最快时效】双优化目标

🎨 风格：科技蓝 + 白 · 单文件 HTML · 零依赖 · 开箱即用

---

## 📖 项目简介

本智能体助手是标准化可订阅的 SaaS 化智能服务，核心能力：输入起运地 A、目的地 B、货物信息、企业自有运力/运价/场站约束，智能体自动完成多式联运路线寻优，输出量化运输方案。

客户不需要从零搭建整套 AI 系统，按版本订阅服务，接入自己企业数据即可使用。

| 维度 | 说明 |
|---|---|
| 服务对象 | 钢厂 · 大宗贸易公司 · 第三方物流企业 |
| 货物类型 | 铁矿石、焦炭、煤、钢材、矿粉等大宗散货/件货 |
| 优化目标 | 最省成本 💰 ｜ 最快时效 ⚡（运单级二选一） |
| 运输方式 | 公路、铁路、内河/海运多式联运组合 |
| 订阅模式 | 按企业账号订阅（基础版 / 专业版 / 企业集群版） |

## ✨ 核心功能

### 1️⃣ 企业基础数据接入（订阅后配置一次）
- 企业自有车队、合作车队运价、协议港口/堆场、铁路专线、装卸费率
- 企业专属约束：自有车辆限重、允许通行路线、固定合作场站、禁运时段、装卸窗口期
- Demo 中 3 个数据开关**真实参与计算**，可实时观察方案变化

### 2️⃣ 运单需求输入
- 起运地 A、目的地 B（12 节点联运网络任选）
- 货物品类、重量、体积（按堆密度自动测算）、装货时间要求
- 优化目标二选一：【最省成本】/【最快时效】

### 3️⃣ 智能体自动推理计算
- 融合公共路网、限重限行、港口船期、铁路班列时刻 + 企业私有数据
- 图网络 DFS 枚举全部可行联运方案 → 约束校验 → 量化对比
- 指标：总成本、总时长、中转节点、滞港/压车风险、装卸等待时间
- 输出推荐主方案 + 备选方案，附带决策理由与 SVG 路线可视化

### 4️⃣ 扰动重规划（专业版及以上）
- 模拟外部扰动：台风封航、暴雪封路、目的港压港、运力骤减
- 智能体自动重算，生成替代运输方案，输出变更影响评估
- 智能区分「切换方案」与「维持方案 + 缓释建议」

### 5️⃣ 方案导出与 API 输出
- 方案报表 JSON 导出（字段兼容主流 TMS/WMS）
- 路线可视化地图
- REST API + Webhook 对接客户自有系统（页面内含请求/响应示例）

### 6️⃣ 扩展能力（企业集群版解锁）
- 与调度智能体、货权风控智能体、料场智能体联动
- 接入物流控制塔协同

## 🧠 演示寻优引擎说明

Demo 内置真实寻优引擎（非静态假数据）：

- 12 节点联运网络（青岛/日照/连云港/天津/邯郸/郑州/西安/南京/武汉/重庆/长沙/成都）
- 18 条运输边（公路/铁路/水运多模式）
- DFS 枚举全部简单路径 → 合并同模式段 → 量化评估 → 模式组合去重 → 多目标排序
- 成本模型：运价 × 距离 × 重量 + 端点作业费 + 中转费；时效模型：距离/速度 + 装卸等待 + 中转等待
- 风险模型：滞港风险（水运段数）/ 压车风险（公路里程 + 运力状态）

> ⚠️ 页面内运输网络、费率与企业数据均为**模拟演示数据**，不代表真实报价。
